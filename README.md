# Fundamental Screener

Python tools to analyse listed companies using financial ratios.

## About
I work in corporate actions at a global bank. I have been investing in financial markets on my own for more than five years. AI is changing this world faster than ever, and I want to be part of it.

## Current features
- `calculate_per(price, eps)`: price-to-earnings ratio
- `calculate_dividend_yield(dividend, price)`: dividend yield (%)
- `calculate_roe(net_income, equity)`: return on equity (%)
